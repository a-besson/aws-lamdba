# AGENTS.md — aws-lambda

Repository-specific instructions, on top of the global rules (`~/AGENTS.md` and
`~/workspace/config/ai/rules/`). This is the only instruction file of the repo: no `CLAUDE.md`
or `GEMINI.md`.

## Stack

Four Maven modules under the `aws-lambda` parent (`com.aws.lambda`), Java 21, functionally
equivalent two by two:

| Module | Stack | Shape |
|---|---|---|
| `quarkus-lambda` | Quarkus | Lambda + Function URL (native zip, `provided.al2023`) |
| `quarkus-lambda-api-gateway-rest` | Quarkus | Lambda + API Gateway REST (native zip) |
| `springboot-lambda` | Spring Boot | Lambda + Function URL (shaded jar, `java21`) |
| `springboot-lambda-api-gateway-rest` | Spring Boot | Lambda + API Gateway REST (shaded jar) |

A behaviour change on one stack must be mirrored on its sibling. Module `artifactId`s must not
change: the Terraform stacks read `target/` paths derived from them. Plugin versions live in the root
`pluginManagement`, Quarkus and Spring BOMs are imported per module and never shared.

## Tests

- `*Test` = unit (surefire), `*IT` = integration (failsafe) on the packaged artifact or the real
  Lambda entry point. No other naming.
- One `NoOpContext` per Spring module; modules stay self-contained (no shared test module).
- `-DskipUTs` / `-DskipITs` select a layer; `-DskipTests` skips both.
- `Floci*IT` deploy the packaged artifact to the Floci emulator (Testcontainers, image pinned by `floci.image` in the
  root pom). One `FlociEmulator` helper per module, no shared test module. Never `aws` against Floci. The only Terraform allowed on Floci is `terraform test` (`task <ns>:tf:test`, `terraform/tests/floci.tftest.hcl`, fake credentials, throwaway container, placeholder package).
- Java is formatted by Spotless (`task format`), checked in `validate` next to Checkstyle.

## Commands

Task is the only entry point: `task --list`. Maven always goes through the root reactor
(`mvn -f <root>/pom.xml -pl <module> -am ...`).

```bash
task build && task test && task it     # all samples
task <quarkus|quarkus-rest|spring|spring-rest>:package
pre-commit run --all-files             # before any hand-off
task kics && task trivy
```

## Rules for this repo

- No Terraform `plan`/`apply`/`destroy` and no `aws` command from an agent; the `tf:*` and `invoke`
  tasks are for the user (use `task --dry`).
- CI never holds cloud credentials and never plans, applies or deploys.
- Security findings: fix, else ignore inline next to the resource with the reason, else
  `.trivyignore` with justification and expiry. Never a global ignore or a lower `fail-on`.
- `TFDOCS.md` is generated by pre-commit, never edited. Providers, modules and Terraform are pinned exactly.
- Stacks use the shared S3 backend (partial config, `backend.hcl` git-ignored). `infra/apigateway-account/` (singleton per
  region) and `infra/state-bucket/` are one-off stacks applied by the user.
- `CHANGELOG.md`: one `## [YYYY-MM-DD] - Daily Log - ...` entry per day.
